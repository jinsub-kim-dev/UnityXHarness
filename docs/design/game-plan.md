# 3D 뱀서 (가제 미정) 기획

## Game Concept
탑다운 3D 시점에서 플레이어는 이동만 직접 조작하고, 공격은 캐릭터가 자동으로 한다. 사방에서 몰려오는 적 무리 사이로 위치를 잡아 살아남는다. 적을 처치해 모은 경험치로 레벨업하고, 레벨업마다 업그레이드 카드 중 하나를 골라 캐릭터를 강하게 만든다. 시간이 갈수록 거세지는 적의 물량을 버티면서 점점 강해지는 성장감과, 죽으면 처음부터 다시 도전하는 짧은 런 반복이 이 게임이 주는 핵심 경험이다.

## Reference Games
- **Soulstone Survivors** — 참고할 요소: 3D 탑다운 시점의 뱀서 루프 구조, 레벨업 시 업그레이드 카드 선택 방식, 시간 경과에 따른 적 물량 증가

## Core Loop
1. 이동 — 플레이어가 WASD로 캐릭터를 움직여 맵 위에서 위치를 잡는다
   ↓
2. 적 접근 — 웨이브 시스템이 적을 스폰하고, 적이 플레이어를 추적해 다가온다. 적과 닿으면 플레이어가 피해를 입는다
   ↓
3. 자동 공격 — 캐릭터가 투사체를 자동 발사해 적을 공격하고, 처치된 적은 경험치를 떨어뜨린다. 플레이어는 이것을 획득한다
   ↓
4. 레벨업 / 사망 — 경험치가 가득 차면 레벨업하고 업그레이드 카드 중 하나를 고른다. 체력이 0이 되면 사망하고, 결과 화면을 거쳐 재시작한다
   ↺ 1로 돌아감 (레벨업 시: 업그레이드로 강해진 상태로, 그동안 시간이 흘러 더 거세진 웨이브를 맞이함 / 사망 시: 초기 상태의 새 런으로)

## Key Systems
| 시스템 | 역할 | 연결되는 루프 단계 |
|---|---|---|
| 플레이어 이동 | PC 키보드 WASD 입력 처리, 탑다운 3D 캐릭터 이동, 추적 카메라 | 1 |
| 적 스폰 & 웨이브 | 플레이어 주변에 적 생성, 경과 시간에 따라 적 수·강도 증가, 적의 플레이어 추적 | 2 |
| 체력 & 피격 | 플레이어·적 공통의 체력 관리, 피해 적용, 사망 판정 | 2, 3, 4 |
| 자동 공격 | 투사체 무기 1종의 타겟 선정(가장 가까운 적)과 자동 발사, 투사체 이동·충돌, 적에게 피해 전달 | 3 |
| 경험치 & 레벨업 | 처치한 적의 경험치 드랍과 획득, 경험치 누적, 레벨업 판정 | 3, 4 |
| 업그레이드 선택 | 레벨업 시 카드 3장 제시, 선택한 스탯(공격력·공격 속도·이동 속도·최대 체력·투사체 개수) 강화 적용 | 4 |
| 런 흐름 | 런 시작, 사망 시 결과 화면, 재시작과 초기화 | 4 |

## Feature Priority
### MVP
- 플레이어 이동 (Top-down 3D, PC 키보드 WASD) — 플레이어가 하는 유일한 직접 조작으로, 루프의 시작점
- 적 스폰 & 웨이브 시스템 (시간 경과에 따른 적 수·강도 증가) — 적이 다가오지 않으면 "적 접근" 단계가 성립하지 않음
- 자동 공격 (투사체 발사 무기 1종) — 루프의 "자동 공격" 단계. 무기 1종으로도 루프가 돎
- 체력 & 피격 (플레이어·적 공통) — 적 처치와 플레이어 사망이 모두 여기에 달려 있어 "사망" 분기가 생김
- 경험치 & 레벨업 — 루프의 "레벨업" 단계이자 반복할 이유가 되는 성장
- 레벨업 시 업그레이드 선택 (카드 3장 중 1장, 강화 스탯: 공격력·공격 속도·이동 속도·최대 체력·투사체 개수) — 레벨업을 체감하게 만드는 레퍼런스의 핵심 재미
- 런 종료 & 재시작 (사망 → 결과 화면 → 재시작) — 사망 이후 다음 판으로 넘어가야 루프가 닫힘

> 수치(경험치 요구량, 웨이브 증가량, 체력·피해량, 스탯 강화량 등)는 임의의 초기값으로 설정하고 구현하면서 조정한다.

### 나중
- 여러 무기 추가 & 스킬 다중 보유·조합 빌드 — 투사체 무기 1종과 스탯 업그레이드로 루프를 검증한 뒤 확장
- 추가 입력 방식 (게임패드, 모바일 가상 조이스틱 등) — MVP는 PC 키보드로 루프를 검증하는 것이 우선
- 여러 클래스(캐릭터) — 캐릭터 1명으로 루프가 완성된 다음에 의미가 있음
- 영구 성장 (런 사이 메타 업그레이드·해금) — 한 판의 재미 확인이 먼저. 세이브 시스템이 선행 조건
- 보스·엘리트 몬스터, 스테이지 타이머·클리어 조건 — MVP는 사망 전까지 생존하는 구조로 충분함
- 아이템 드랍(회복·자석 등), 크래프팅 — 루프를 풍부하게 하지만 루프가 도는 데 필수는 아님
- 멀티 스테이지·맵 — 맵 1개로 루프 검증이 가능함
- 협동(co-op) — 범위가 크고 네트워크가 선행 조건

## Development Order
1. 플레이어 이동 — 모든 시스템의 기준점. WASD 탑다운 3D 조작감과 카메라 확인
2. 적 스폰 & 웨이브 — 적이 생성되어 플레이어를 추적하는지, 시간에 따라 물량이 늘어나는지 확인
3. 체력 & 피격 — 적과 닿았을 때 피해와 사망 판정 확인. 적 처치의 전제 조건
4. 자동 공격 — 이 단계부터 "이동 → 적 접근 → 투사체 자동 공격 → 처치"를 실제로 플레이해볼 수 있음
5. 런 흐름 — 사망 → 결과 화면 → 재시작으로 사망 분기의 루프가 닫힘
6. 경험치 & 레벨업 — 처치 보상이 쌓여 레벨이 오르는지 확인
7. 업그레이드 선택 — 레벨업 분기까지 포함해 핵심 루프 전체가 한 바퀴 돎 (MVP 완료)
8. 이후 "나중" 항목을 우선순위에 따라 진행 (여러 무기 → 클래스 → 영구 성장 …)
