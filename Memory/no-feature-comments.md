metadata:
  type: feedback
---

코드를 작성할 때 기능(블록·메서드)별로 무엇을 하는지 설명하는 주석을 달지 않는다.

**Why:** 사용자가 명시적으로 요청함 (2026-10-04).
**How to apply:** C# 코드 생성·수정 시 "// 이동 처리", "// 체력 감소" 같은 기능 설명 주석이나 XML 문서 주석을 추가하지 않는다. 코드는 네이밍으로 의도를 드러낸다.
